# CS 310 client guide

This frontend is made with a combination of:
- Material UI (for components)
- React (to wire things up)
- Vite (JS compiler and development server)

To set up the client (assume that you started the server earlier):
- `yarn install`: install the dependencies
- `yarn build`: compile the front-end
- `yarn preview`: deploy the front-end. By default it would be at port 4173.

You can also invoke `yarn dev` which will open up the development front-end at port 5173; this allows you to edit the code and view the changes in realtime.

A demonstration can be seen here: [https://youtu.be/-mqHclE-w5E](https://youtu.be/-mqHclE-w5E).
